## 專長（前端與協作）

**主軸**：前端網頁開發、系統協作能力

1. 熟悉 **HTML、CSS、JavaScript（ESM）**，具網頁切版、互動與狀態管理能力；能實作響應式介面（RWD）、載入狀態與錯誤提示等使用者體驗細節。
2. 熟悉 **React（含 React 19）** 與 **Vite** 建置流程，具元件化開發經驗；善用 Hooks（如 `useState`、`useEffect`、`useMemo`、`useCallback`）與自訂 Hook 封裝較複雜邏輯，維持畫面與資料流清晰。
3. 具 **RESTful API** 串接經驗（例如 TMDb），能處理分頁、排序、篩選、防抖（debounce）等請求節流與 UI 協調；熟悉 `import.meta.env` / 環境變數管理金鑰與設定。
4. 熟悉前端資料持久化與離線體驗設計，能使用 **localStorage** 保存使用者偏好與清單／歷程。
5. 具備 **AI／LLM 應用**基礎實務：串流回應處理、結構化輸出（Prompt 與 JSON 解析、降級策略），並整合 **Ollama / Groq / Gemini**；開發環境能透過 Vite dev server proxy 處理 CORS 等連線問題。
6. 熟悉團隊開發與版本控制（**Git / GitHub**），並使用 **ESLint** 維持程式風格與可讀性。
7. 具備程式邏輯與問題分析能力，曾撰寫自動化測試腳本與 MTK AI 技術文件（RST），協助流程與可維護性。

**標籤**：`JavaScript` `ReactJS` `HTML` `CSS`
